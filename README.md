Project Name: Apartment Visitor Management System (AVMSS)

Tech Stack: PHP, MySQL, Bootstrap 4, JavaScript / jQuery

Core Modules: Visitor pass generation, visitor logs, date-range reports, admin dashboard, password management

Setup Instructions:

Import the SQL file located in SQL File/avmsdb.sql into phpMyAdmin/MySQL.

Configure database credentials in includes/dbconnection.php.

Run via a local PHP server (e.g., XAMPP/WampServer).
